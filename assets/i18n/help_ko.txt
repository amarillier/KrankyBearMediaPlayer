• 라이브러리 → 폴더 추가: 음악 폴더를 선택하면 카탈로그로 검색됩니다.
  원하는 만큼 폴더 / 위치를 추가하세요.
• 라이브러리 → 폴더 관리: 모든 감시 폴더와 트랙 수를 확인하고, 추가, 재배치
  (이동된 드라이브로 다시 가리키기), 다시 검색, 또는 제거할 수 있습니다. 제거하면
  그 트랙이 라이브러리에서 빠지지만 디스크의 파일은 절대 삭제되지 않습니다.
• 라이브러리 → 모두 다시 검색: 감시 폴더를 다시 검색하여 새로운 또는 변경된 파일을 가져옵니다.
• 라이브러리는 작은 SQLite 데이터베이스입니다. 제목, 아티스트, 앨범, 장르, 연도,
  트랙 번호, 내장 앨범 표지가 각 파일에서 읽힙니다.

음악 재생:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 아무 트랙이나 더블클릭하면 그 지점부터 목록의 나머지까지 재생이 시작됩니다.
• 트랜스포트 (하단 바): 이전, 재생/일시정지, 정지, 다음.
• 재생 메뉴: 셔플은 대기열을 무작위 순서로 재생합니다. 반복 → 끄기 / 전체 반복
  (대기열 반복) / 한 곡 반복 (현재 트랙 반복). 두 설정 모두 기억됩니다. 다음/이전으로
  건너뛰면 한 곡 반복 중에도 항상 다음으로 이동합니다.
• 재생 → ReplayGain: 켜면 ReplayGain 태그가 있는 트랙이 일관된 음량으로 재생됩니다
  (피크 제한이 적용되어 증폭된 트랙이 클리핑되지 않음). 기본값은 끄기입니다.
  "앨범 게인 우선"은 앨범 태그가 있을 때 앨범 음량으로 정규화하여 (앨범 고유의
  조용함/시끄러움 균형을 보존) 처리하고, 없으면 트랙 게인으로 대체합니다.
  직접 파일에 태그를 넣으려면 트랙을 표시하고 라이브러리 → 선택 항목 ReplayGain 검색…
  (또는 우클릭 → ReplayGain 검색)을 사용하세요. 앱이 음량을 측정하고 (BS.1770 /
  ReplayGain 2.0) 트랙 + 앨범 ReplayGain 태그를 MP3/FLAC에 기록합니다.
• 재생 → 이퀄라이저…: 음색을 실시간으로 다듬는 10밴드 그래픽 이퀄라이저
  (31 Hz – 16 kHz, ±12 dB)입니다. 사용을 체크하고, 밴드 슬라이더를 드래그하거나, 프리셋
  (Flat, Bass Boost, Vocal, Rock, …)을 선택하세요. "프리셋 저장…"으로 직접 만든 설정을
  저장하고 "프리셋 삭제"로 제거하세요. 초기화 (Flat)는 밴드를 0으로 되돌립니다. 끄면 음색에 영향이 없습니다.
• 재생 → 트랙 전환: 간격 (기본값), 간격 없음 (트랙이 무음 없이 바로 이어짐), 또는
  크로스페이드 (나가는 트랙이 페이드아웃되며 다음 트랙이 페이드인됨).
  간격 없음/크로스페이드는 실험적 기능입니다.
• 재생 대기열 (재생 → 재생 대기열 표시): 재생 순서대로 무엇이 대기 중인지 보여주며
  현재 트랙은 ▶로 표시됩니다. 트랙을 우클릭 → 대기열에 추가 (또는 라이브러리 → 선택
  항목을 대기열에 추가 / 표시된 항목 모두 대기열에 추가)하면 재생 중인 항목을 방해하지 않고 추가됩니다.
  대기열 창에서: 선택한 트랙을 재생, 제거, 위로/아래로 이동, 또는
  모두 지우기를 할 수 있습니다.
• 툴바나 트랜스포트 버튼 위에 마우스를 올리면 기능을 설명하는 툴팁이 나타납니다.
• 탐색 바는 경과 / 전체 시간을 보여줍니다 — 드래그하여 트랙 내에서 이동하세요.
• 두 개의 볼륨 컨트롤이 오른쪽 하단에 있습니다:
  - "앱"은 이 플레이어 자체의 음량만 조절합니다 (실행 간 기억됨).
  - "시스템"은 컴퓨터의 마스터 출력 볼륨을 조절하며 옆에 음소거 토글이 있습니다.
    볼륨 키나 OS 믹서로 변경한 것을 포함하여 시스템 음량과 동기화를 유지하며,
    이 앱뿐만 아니라 컴퓨터 전체의 볼륨을 움직입니다.
• "밸런스"는 좌/우 스테레오 밸런스를 설정합니다 (실행 간 기억됨). 부드러운 중앙
  디텐트가 있으며, 옆의 "C" 버튼을 누르면 정중앙으로 돌아갑니다.
  스피커가 대칭으로 배치되지 않았을 때 유용합니다.
• 선택된 행 표시기는 현재 재생 중인 트랙을 따라갑니다.

별점 및 재생 추적:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 별점은 수동입니다: 직접 1~5개의 별점을 설정합니다. 재생 수는 별도로
  추적되며 (자체 열) 별로 변환되지 않습니다.
• 트랙의 별점 열에서 별을 클릭하여 별점을 설정하고, 같은 별을 다시 클릭하면
  지워집니다 (별 없음으로 되돌아감). "별점:" 버튼 (하단)과 우클릭 메뉴도
  동일하게 작동합니다. 다섯 개의 별 모두 클릭할 수 있습니다.
• 보기 → 재생 집계 기준: 재생 수가 올라가기 전에 트랙이 얼마나 재생되어야 하는지
  선택합니다 (25 / 50 / 75 / 90% 또는 트랙 끝). 건너뛰기는 절대 집계되지 않습니다.
• 팁: 재생 수 (열 필터)로 필터링하면 예를 들어 5번 재생한 모든 항목을 찾은 다음
  원하는 대로 별점을 매길 수 있습니다.

찾기 및 정리:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 검색 상자 (상단): 입력하는 동안 제목, 아티스트, 앨범, 장르 또는 파일명으로 필터링합니다.
• 열 필터 (보기 → 열 필터 표시): 열별 입력 상자 행입니다 — 제목, 아티스트, 앨범,
  장르에 입력하면 부분 문자열과 일치합니다. 연도와 재생 수는 패턴을 받습니다
  (예: 연도 202[456]는 2024-2026과 일치, 재생 수 5 = 정확히 다섯 번 재생, 0 =
  한 번도 재생 안 함). 이들은 서로 그리고
  검색/표시 필터와 결합됩니다. ✕ 버튼으로 지우세요. 행을 숨기면
  필터도 지워집니다.
• "표시" 필터 (상단): 모든 트랙, 별점 없음, 정확한 별 개수, 또는 N개 이상의 별.
• 열 머리글을 클릭하면 정렬됩니다. 다시 클릭하면 역순이 됩니다 (표지 열은 정렬되지 않음).
• 보기 메뉴: 선택적으로 길이, 형식, 비트레이트, 장르, 트랙 번호, 파일명
  열을 표시할 수 있습니다 (길이는 기본으로 켜져 있고 나머지는 꺼짐. 선택은 기억됨).
  길이와 비트레이트는 앱이 백그라운드에서 각 트랙의 재생 시간을 읽으므로
  시작/검색 직후 잠시 후 채워지며, 잠깐 비어 있을 수 있습니다.
• 재생 중인 트랙으로 이동: 하단 바에서 그 이름을 클릭하거나 툴바의
  "재생 중" 버튼 (다시 검색 옆)을 사용하세요. 스크롤, 검색, 정렬 후 유용합니다.
  (트랙을 찾기만 할 뿐, 재생을 시작하거나 정지하지는 않습니다.)
• 이어서 계속하기: 앱은 정렬 순서를 기억하고, 다시 실행할 때 마지막으로
  재생하던 트랙을 선택하고 그곳으로 스크롤합니다 (자동 재생은 하지 않음).
• 다른 곳으로 트랙 복사: 보기 → 선택 체크박스는 ✓ 열을 추가합니다. 행을 표시하고
  (✓ 머리글을 클릭하면 표시된 항목 모두 토글), 또는 라이브러리 → 표시된 항목 모두 선택.
  그런 다음 라이브러리 → 선택 항목 복사 위치…에서 단순 또는 아티스트/앨범 폴더로 정리를
  선택하고 대상을 선택할 수 있습니다 - 예: 별 5개로 필터링하고 모두 표시한 후
  USB 드라이브로 복사. 진행 대화상자가 각 파일을 보여주며 취소할 수 있습니다.
  (이름 충돌 시 " (2)" 접미사가 붙으며, 아무것도 덮어쓰지 않습니다.)
• 트랙을 우클릭하면 재생, 별점, 앨범 표지 추가 (로컬 이미지 파일 또는 URL,
  라이브러리에 저장됨), 파일 관리자에서 보기, 전체 경로 표시 (복사
  버튼 포함)를 할 수 있습니다.
• 우클릭 파일 이름 변경… / 태그 편집… / 별점 설정은 보통 해당 트랙
  하나에만 적용됩니다. 하지만 표시된 (✓) 트랙을 우클릭하면 표시된 전체
  세트에 적용됩니다 — 메뉴 레이블이 어느 쪽인지 알려줍니다 (예: "표시된 5개의 태그 편집…",
  "별점 설정 (5개 표시됨)").
• 파일 이름 변경… (우클릭)은 토큰 패턴을 사용하여 태그를 기반으로 디스크의
  파일 이름을 변경합니다 — %track% %title% %artist% %album% %albumartist% %year%
  %genre% — 예: "%track% %title% - %artist%". 적용하기 전에 라이브 미리보기로 새 이름을
  보여줍니다. 확장자는 항상 유지되고 카탈로그는 그 자리에서 업데이트됩니다
  (다시 검색 없음). %track%은 두 자리로 0이 채워집니다.
• 태그 편집… (우클릭)은 제목, 아티스트, 앨범, 앨범
  아티스트, 연도, 트랙 번호, 장르, 설명, 내장 표지 이미지에 대한 편집기를 엽니다. 변경 사항은
  MP3와 FLAC의 경우 파일에 다시 기록됩니다. OGG와 WAV는 지금은 읽기 전용으로
  열립니다. 파일명에서 태그 가져오기… (해당 편집기 내)는 동일한 토큰 패턴을 사용하여
  파일 이름을 필드로 파싱하며, 저장하기 전에 검토할 수 있습니다 — 스스로 기록하지는
  않습니다. 현재 재생 중인 트랙을 편집하면 파일을 저장할 수 있도록 재생이 먼저
  정지됩니다. 카탈로그 (및 모든 썸네일)는 즉시 업데이트됩니다.
• 여러 항목의 태그를 한 번에 편집: 트랙을 표시한 후 (선택 체크박스 / 표시된 항목
  모두 선택), 라이브러리 → 선택 항목 태그 편집… 한 번에 네 가지 종류의
  변경을 결합할 수 있습니다: (1) 파일명에서 — 토큰 패턴으로 이름을 파싱하여 각
  트랙에 제목/아티스트/트랙 번호 등을 설정 (파일명에서 태그 가져오기의 일괄
  형태. 일치하지 않는 파일은 그대로 둠); (2) 필드 설정 — 아티스트,
  앨범, 앨범 아티스트, 장르, 연도 또는 설명을 체크하여 전체 선택에 하나의 값을
  부여 (이들은 패턴을 재정의함); (3) 찾아 바꾸기 — 선택 항목 전체에서 한 필드 내의 텍스트를
  변경 (예: "feat."→"ft.", 선택적으로 대소문자 무시); (4) 표지 이미지 — 모두에 하나의
  이미지를 표지로 설정하거나, 모두에서 표지를 제거. 진행 대화상자가 각 파일을 취소
  버튼과 함께 보여줍니다. OGG/WAV는 건너뜁니다.
• 여러 항목을 한 번에 이름 변경: 트랙을 표시한 후 라이브러리 → 패턴으로 선택 항목 이름
  변경… 미리보기 목록이 각 이전 → 새 이름을 보여줍니다. 적용하면 모두 이름이 변경됩니다 (이름
  충돌 시 " (2)" 접미사가 붙고 아무것도 덮어쓰지 않음). 취소 버튼이 있습니다.
• 라이브러리 보고서 (라이브러리 → 라이브러리 보고서…): 아티스트, 앨범, 또는 장르별로
  그룹화하거나 계층적으로 (아티스트 → 앨범, 앨범 → 아티스트, 장르 →
  아티스트), 또는 평면 트랙 목록으로 컬렉션을 요약합니다. "트랙 나열"을 체크하면 각 그룹을 펼쳐서
  그 안의 트랙을 표시합니다. 오름차순/내림차순 토글로 이름이나 연도로 정렬하고,
  전체 라이브러리와 현재 필터링된 보기 사이를 전환하며,
  CSV 내보내기…로 보고서를 저장할 수 있습니다. "중복"을 선택하면 아티스트 + 제목,
  아티스트 + 제목 + 앨범, 또는 파일명으로 일치시켜 중복 트랙을 찾습니다. 각 세트는
  모든 사본을 전체 경로와 재생 수와 함께 나열하여 어느 것을 남길지 결정할 수 있습니다.

재생목록:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 정적 재생목록 (재생목록 메뉴): 재생목록 저장…은 현재 보고 있는 트랙을
  휴대용 .m3u8 파일에 기록하며, 파일 기준 상대 경로를 사용하여 재생목록과
  음악이 함께 이동합니다 (예: USB 스틱). 재생목록 열기…는
  하나를 불러와 재생합니다. 카탈로그에 여전히 있는 파일은 별점/재생 수를 유지합니다.
• 스마트 재생목록 (재생목록 → 새 스마트 재생목록…): 필터 조건을 저장합니다 —
  별점과 선택적 장르 / 아티스트 / 앨범 (부분 일치, 대소문자 무시 — 예:
  "Wickham"이 "Phil Wickham"과 일치), 그리고 자유 텍스트 검색 — 이름 아래에. 재생목록
  메뉴에서 선택하면 조건을 실시간으로 다시 적용합니다 (상태 표시줄에
  ♫ <이름> 표시). 라이브러리가 변경되면 자동으로 업데이트됩니다. 스마트 재생목록
  관리…에서는 저장된 재생목록의 조건을 편집하거나 (연필 버튼, 이름도 변경
  가능) 더 이상 원하지 않는 것을 삭제할 수 있습니다.

창 및 시스템 트레이:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 시스템 트레이 아이콘 + 메뉴가 컨트롤을 반영합니다: 모든 창 표시/숨기기,
  재생/일시정지, 이전, 다음, 정지, 종료.
• 모든 창 숨기기는 앱을 치워 두고 재생을 일시정지합니다. 모든 창 표시는 다시
  불러옵니다 (재생을 눌러 재개).
• 메인 창은 실행 간 크기를 기억합니다.

휴대용 라이브러리 (컴퓨터나 드라이브 간 이동):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 트랙 위치는 각 감시 폴더를 기준으로 상대적으로 저장되므로, 휴대용
  드라이브가 한 PC에서는 D:\로, 다른 PC에서는 E:\로 마운트되면 그냥
  라이브러리 → 폴더 재배치로 폴더를 다시 가리키세요 — 그 아래의 모든 트랙이 따라오며
  재생 수와 별점을 유지합니다.
• 데이터베이스 위치는 -db 명령줄 플래그, KBMP_DB
  환경 변수, 또는 보기 → 환경설정 → 데이터베이스 위치 (적용하려면 다시
  시작)로 설정할 수 있습니다. 기본적으로 앱 옆에 위치합니다 (USB 스틱에서 유용).

환경설정:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 보기 → 환경설정… (Alt+R)은 일반적인 설정을 한곳에 모읍니다:
  테마, 언어, "재생 집계 기준" 임계값, 재생 볼륨 (실행 간
  기억됨), 시작 시 이퀄라이저를 열지 여부, 선택적 열,
  데이터베이스 위치. 동일한 토글이 빠른 일회성 변경을 위해 보기 메뉴에도 남아 있습니다.

스마트 기능:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ 내장 앨범 표지가 테이블과 재생 중 영역에 썸네일로 표시됩니다.
✨ 라이브러리가 변경되면 실시간으로 다시 평가하는 스마트 재생목록.
✨ 테마 지원: 밝은, 어두운, 또는 시스템 테마 (보기 메뉴).

키보드 단축키:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Alt+P — 재생 / 일시정지
• Alt+→ — 다음 트랙   • Alt+← — 이전 트랙
• Alt+H — 모든 창 숨기기 (및 일시정지). 다시 표시하는 단축키는 의도적으로 없습니다 —
  시스템 트레이나 보기 → 모든 창 표시를 사용하세요.
• Alt+R — 환경설정
• Cmd/Ctrl+Q — 종료   • Cmd/Ctrl+W — 창 닫기   • Cmd/Ctrl+M — 최소화
