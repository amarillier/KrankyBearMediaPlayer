{{app_name}} - 音楽ライブラリの管理・再生アプリ

はじめに:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• ライブラリ → フォルダーを追加: 音楽のフォルダーを選ぶと、カタログにスキャンされます。
  フォルダー / 場所はいくつでも追加できます。
• ライブラリ → フォルダーを管理: トラック数とともにすべての監視フォルダーを表示します。追加、
  再配置（移動したドライブへの再指定）、再スキャン、削除ができます。削除すると、その
  トラックはライブラリから外れますが、ディスク上のファイルは決して削除されません。
• ライブラリ → すべて再スキャン: 監視フォルダーを再スキャンして、新規・変更されたファイルを取り込みます。
• ライブラリは小さな SQLite データベースです。タイトル、アーティスト、アルバム、ジャンル、年、
  トラック番号、埋め込みアルバムアートが各ファイルから読み取られます。

音楽の再生:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 任意のトラックをダブルクリックすると、そこから残りのリストを通して再生が始まります。
• トランスポート（下部バー）: 前へ、再生 / 一時停止、停止、次へ。
• 再生メニュー: シャッフルはキューをランダムな順序で再生します。リピート → オフ / すべてリピート
  （キューをループ）/ 1曲リピート（現在のトラックをループ）。どちらも記憶されます。次へ/前へ
  でのスキップは、1曲リピート中でも常に次へ進みます。
• 再生 → ReplayGain: オンにすると、ReplayGain タグが付いたトラックが一定の音量で再生されます
  （ピークが制限されるため、ブーストされたトラックでもクリップしません）。既定ではオフです。
  「アルバムゲインを優先」は、アルバムタグがある場合にアルバムの音量で正規化し（アルバム自体の
  静かさ/大きさのバランスを保持）、なければトラックゲインにフォールバックします。
  ファイルに自分でタグを付けるには、マークして ライブラリ → 選択項目の ReplayGain をスキャン…
  （または右クリック → ReplayGain をスキャン）を使います。アプリが音量を測定し（BS.1770 /
  ReplayGain 2.0）、トラックとアルバムの ReplayGain タグを MP3/FLAC に書き込みます。
• 再生 → イコライザー…: 音色をリアルタイムで整える10バンドのグラフィックイコライザー
  （31 Hz – 16 kHz、±12 dB）です。「イコライザーを有効化」にチェックを入れ、バンドのスライダーを
  ドラッグするか、プリセット（Flat、Bass Boost、Vocal、Rock など）を選びます。独自の設定は
  「プリセットを保存…」で保存し、「プリセットを削除」で削除できます。リセット（Flat）は
  バンドをゼロにします。無効化すると音は素通りします。
• 再生 → トラックの切り替え: ギャップ（既定）、ギャップレス（トラックが無音なしで連続）、
  またはクロスフェード（再生中のトラックがフェードアウトしながら次がフェードイン）。
  ギャップレス/クロスフェードは実験的です。
• 再生キュー（再生 → 再生キューを表示）: 再生順に並んでいる曲を確認できます。現在のトラックには
  ▶ が付きます。トラックを右クリック → キューに追加（またはライブラリ → 選択項目をキューに追加 /
  表示中をすべてキューに追加）すると、再生中のものを中断せずに末尾に追加されます。
  キューウィンドウでは、選択したトラックの再生、削除、上へ/下への移動、すべてクリアができます。
• ツールバーやトランスポートのボタンにカーソルを合わせると、その動作を説明するツールチップが表示されます。
• シークバーには経過時間 / 合計時間が表示されます — ドラッグするとトラック内の位置に移動できます。
• 右下に2つの音量コントロールがあります:
  - 「アプリ」はこのプレーヤー自身の音量だけを調整します（起動をまたいで記憶されます）。
  - 「システム」はコンピューターのマスター出力音量を操作し、隣にミュート切り替えがあります。
    音量キーや OS のミキサーで行った変更を含め、システムの音量と同期し続け、このアプリだけでなく
    マシン全体の音量を動かします。
• 「バランス」は左右のステレオバランスを設定します（起動をまたいで記憶されます）。中央付近に
  ソフトなディテントがあり、隣の「C」ボタンを押すとぴったり中央に戻ります。
  スピーカーが左右対称に配置されていないときに便利です。
• 選択行のインジケーターは、現在再生中のトラックを追従します。

評価と再生の記録:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 評価は手動です。1〜5の星評価を自分で設定します。再生回数は別に記録され（専用の列）、
  星には変換されません。
• トラックの評価列の星をクリックして評価を設定します。同じ星をもう一度クリックすると
  クリアされます（星なしに戻ります）。「評価:」ボタン（下部）と右クリックメニューでも同じことができます。
  5つの星はすべてクリックできます。
• 表示 → 再生としてカウントする位置: 再生回数が増えるまでにトラックをどれだけ再生する必要があるかを
  選びます（25 / 50 / 75 / 90% またはトラックの最後）。スキップは決してカウントされません。
• ヒント: 再生回数（列フィルター）で絞り込むと、例えば5回再生したものをすべて見つけて、
  好きなように評価できます。

検索と整理:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 検索ボックス（上部）: 入力に応じて、タイトル、アーティスト、アルバム、ジャンル、ファイル名で絞り込みます。
• 列フィルター（表示 → 列フィルターを表示）: 列ごとのボックスの行です — タイトル、アーティスト、
  アルバム、ジャンルに入力すると部分一致します。年と再生回数はパターンを受け付けます
  （例: 年 202[456] は 2024〜2026 に一致。再生回数 5 = ちょうど5回再生、0 = 一度も再生していない）。
  これらは互いに、また検索/表示フィルターと組み合わさります。✕ ボタンでクリアでき、行を隠しても
  クリアされます。
• 「表示」フィルター（上部）: すべて、未評価、特定の星数、または N星以上。
• 列ヘッダーをクリックすると並べ替わり、もう一度クリックすると逆順になります（アートの列は並べ替えできません）。
• 表示メニュー: 任意で 長さ、形式、ビットレート、ジャンル、トラック番号、ファイル名の列を表示できます
  （長さは既定でオン、その他はオフ。選択は記憶されます）。長さとビットレートは、アプリが各トラックの
  再生時間をバックグラウンドで読み取るため、起動/スキャンの直後に順次埋まります。そのため一瞬空白になることがあります。
• 再生中のトラックへジャンプ: 下部バーのその名前をクリックするか、ツールバーの「再生中」ボタン
  （再スキャンの隣）を使います。スクロール、検索、並べ替えで離れた後に便利です。
  （トラックを見つけるだけで、再生を開始・停止することはありません。）
• 続きから再開: アプリは並べ替え順を記憶し、再起動時に最後に再生していたトラックを選択して
  スクロールします（自動再生はしません）。
• トラックを別の場所へコピー: 表示 → 選択チェックボックスで ✓ 列が追加されます。行にチェックを入れる
  （✓ ヘッダーをクリックすると表示中をすべて切り替え）か、ライブラリ → 表示中をすべて選択を使います。
  次に ライブラリ → 選択項目を次へコピー… で、フラットか アーティスト/アルバムのフォルダーに整理かを
  選び、コピー先を選びます — 例えば星5に絞ってすべてマークし、USB ドライブにコピーします。
  進行状況ダイアログに各ファイルが表示され、キャンセルできます。
  （名前の衝突には「 (2)」が付き、何も上書きされません。）
• トラックを右クリックすると、再生、評価、アルバムアートを追加（ローカルの画像ファイルまたは URL、
  ライブラリに保存されます）、ファイルマネージャーで表示、フルパスを表示（コピーボタン付き）ができます。
• 右クリックの ファイルを改名… / タグを編集… / 評価を設定 は通常そのトラックにのみ作用します。ただし、
  マーク済み（✓）のトラックを右クリックすると、マークされたセット全体に作用します — メニューのラベルに
  どちらかが示されます（例:「マーク中の5件のタグを編集…」「評価を設定（5件マーク中）」）。
• ファイルを改名…（右クリック）は、トークンのパターン — %track% %title% %artist% %album%
  %albumartist% %year% %genre% — を使って、タグからディスク上のファイルを改名します
  （例:「%track% %title% - %artist%」）。適用前に新しい名前がライブプレビューで表示されます。拡張子は
  常に保持され、カタログはその場で更新されます（再スキャン不要）。%track% は2桁にゼロ埋めされます。
• タグを編集…（右クリック）は、タイトル、アーティスト、アルバム、アルバムアーティスト、年、
  トラック番号、ジャンル、コメント、埋め込みカバー画像のエディターを開きます。変更は MP3 と FLAC では
  ファイルに書き戻されます。OGG と WAV は今のところ読み取り専用で開きます。ファイル名からタグ…
  （このエディター内）は、同じトークンパターンを使ってファイル名を各フィールドに解析し、保存前に
  確認できるようにします — 勝手に書き込むことはありません。現在再生中のトラックを編集すると、
  ファイルを保存できるように先に再生が停止します。カタログ（およびサムネイル）はすぐに更新されます。
• 複数を一度に編集: トラックをマークし（選択チェックボックス / 表示中をすべて選択）、次に
  ライブラリ → 選択項目のタグを編集… 一度の処理で4種類の変更を組み合わせられます: (1) ファイル名から
  — トークンパターンで各トラックの名前を解析して タイトル/アーティスト/トラック番号 などを設定します
  （ファイル名からタグの一括版。一致しないファイルはそのまま）。(2) フィールドを設定 — アーティスト、
  アルバム、アルバムアーティスト、ジャンル、年、コメントにチェックを入れると、選択全体に1つの値を
  与えます（これらはパターンを上書きします）。(3) 検索して置換 — 選択全体で1つのフィールド内のテキストを
  変更します（例:「feat.」→「ft.」、任意で大文字小文字を無視）。(4) カバーアート — すべてのカバーに1つの
  画像を設定するか、すべてのカバーを削除します。進行状況ダイアログに各ファイルがキャンセルボタン付きで
  表示されます。OGG/WAV はスキップされます。
• 複数を一度に改名: トラックをマークし、次に ライブラリ → 選択項目をパターンで改名… プレビューリストに
  各 旧 → 新 の名前が表示されます。適用するとすべて改名されます（名前の衝突には「 (2)」が付き、何も
  上書きされません）。キャンセルボタン付きです。
• ライブラリレポート（ライブラリ → ライブラリレポート…）: コレクションを アーティスト、アルバム、
  またはジャンル別にまとめます。階層的に（アーティスト → アルバム、アルバム → アーティスト、
  ジャンル → アーティスト）、またはフラットなトラック一覧として表示できます。「トラックを一覧表示」に
  チェックを入れると、各グループを展開してその中のトラックを表示します。名前または年で昇順/降順を
  切り替えて並べ替え、ライブラリ全体と現在のフィルター済みビューを切り替え、CSV をエクスポート… で
  レポートを保存できます。「重複」を選ぶと、アーティスト + タイトル、アーティスト + タイトル + アルバム、
  またはファイル名で一致する重複トラックを見つけます。各セットにはすべてのコピーがフルパスと再生回数とともに
  一覧表示され、どれを残すか判断できます。

プレイリスト:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 静的プレイリスト（プレイリストメニュー）: プレイリストを保存… は、現在表示しているトラックを
  ポータブルな .m3u8 ファイルに書き出します。パスはファイルからの相対パスなので、プレイリストと
  その音楽は一緒に持ち運べます（例: USB スティック上）。プレイリストを開く… はそれを読み込んで再生します。
  カタログにまだあるファイルは、星と再生回数を保持します。
• スマートプレイリスト（プレイリスト → 新しいスマートプレイリスト…）: フィルター条件 — 評価、および
  任意の ジャンル / アーティスト / アルバム（部分一致、大文字小文字を無視 — 例:「Wickham」は
  「Phil Wickham」に一致）、加えて自由入力の検索 — を名前を付けて保存します。プレイリストメニューから
  選ぶと条件がリアルタイムで再適用されます（ステータスバーに ♫ <名前> が表示されます）。ライブラリの
  変更に応じて自動的に更新されます。スマートプレイリストを管理… では、保存したプレイリストの条件を
  編集（鉛筆ボタン。改名もできます）したり、不要になったものを削除したりできます。

ウィンドウとシステムトレイ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• システムトレイのアイコン + メニューがコントロールをミラーします: すべてのウィンドウを表示/隠す、
  再生 / 一時停止、前へ、次へ、停止、終了。
• すべてのウィンドウを隠すはアプリをしまって再生を一時停止します。すべて表示で元に戻ります
  （再生を押すと再開します）。
• メインウィンドウは起動をまたいでサイズを記憶します。

ポータブルライブラリ（マシンやドライブ間の移動）:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• トラックの場所は各監視フォルダーからの相対パスで保存されます。そのため、ポータブルドライブが
  あるPCで D:\ として、別のPCで E:\ としてマウントされても、
  ライブラリ → フォルダーを再配置 でフォルダーを再指定するだけです — その下のすべてのトラックが
  追従し、再生回数と評価を保持します。
• データベースの場所は、-db コマンドラインフラグ、KBMP_DB 環境変数、または
  表示 → 環境設定 → データベースの場所（反映には再起動が必要）で設定できます。既定では
  アプリの隣に置かれます（USB スティック上で便利）。

環境設定:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 表示 → 環境設定…（Alt+R）は、よく使う設定を1か所にまとめます:
  テーマ、言語、「再生としてカウントする位置」のしきい値、再生音量（起動をまたいで記憶）、
  起動時にイコライザーを開くかどうか、任意の列、データベースの場所。同じ切り替えは、その場で
  一度だけ変更するために表示メニューにも残っています。

スマート機能:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ 埋め込みアルバムアートを、テーブルと再生中エリアにサムネイルとして表示。
✨ ライブラリの変更に応じてリアルタイムで再評価されるスマートプレイリスト。
✨ テーマ対応: ライト、ダーク、またはシステムテーマ（表示メニュー）。

キーボードショートカット:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Alt+P — 再生 / 一時停止
• Alt+→ — 次のトラック   • Alt+← — 前のトラック
• Alt+H — すべてのウィンドウを隠す（そして一時停止）。隠した後は、システムトレイまたは
  表示 → すべてのウィンドウを表示 を使って再び表示してください（Alt+S はメインウィンドウが
  表示されているときのみ機能します）。
• Alt+S — すべてのウィンドウを表示。メインウィンドウと、開いているすべての副ウィンドウ
  （イコライザー、ヘルプなど）を前面に表示します。
• Alt+R — 環境設定
• Cmd/Ctrl+Q — 終了   • Cmd/Ctrl+W — ウィンドウを閉じる   • Cmd/Ctrl+M — 最小化

既知の制限:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️  対応する音声形式: MP3、FLAC、WAV、OGG（M4A/AAC/ALAC はまだ非対応）。
⚠️  ミュージックビデオの再生は計画中ですが、まだ利用できません。
