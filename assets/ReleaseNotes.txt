Release notes
KrankyBear MediaPlayer: - Windows, Linux and MacOS media player


Future ideas:
- LATER: extend "Add album art" to multiple selected tracks at once, and optionally embed into the file (vs catalog-only)
- MEDIUM: tag editor text components beyond just attaching album art
- MEDIUM: Preferences or other option to show configured / previously added disks, folders etc
- MEDIUM: Possible internationalization with assets/i18n language support - this is a bigger thing and will mean extracting menu items, main window messages, about, help, update checker etc to allow for alternate languages
- MEDIUM: Playlist create static and dynamic (e.g. 5 stars and genre= and aerist=) using filter and select logic, ability to save a playlist file to specified location
- LOWER: Graphic equalizer possible, with presets?
- LOWER: Possible allow simple music video play, lower priority, even if only play music but not the video for example
- LOW: Skins - maybe never, that becomes much more complex
- LOW: Animations, cute, not necessary and becomes much more complex
- LOW: Possibly never consider seriously - ability to convert audio formats, resample at ower bitrates? Probably not


Version 0.2.0 - June 8, 2026

✨ NEW FEATURES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Multi-column sort: click a header to sort, Shift+click another for a secondary
  tie-breaker (e.g. Album then Track #). Large arrow = primary, small = secondary.
- Discreet update check: an automatic once-per-day check on launch (shows the
  dialog only if an update is available); the manual "Check for Updates" still
  works any time. Cache stored per-user as latestcheck-KrankyBearMediaPlayer.json.
- Add album art (right-click a track) from a local image file or a URL; stored in
  the library and shown in the table + now-playing. No online cover search.
- Right-click: Show in Finder/Explorer/File Manager, and Show full path (copyable)
- Select & copy: View > Selection checkboxes adds a tick column (or Library >
  Select All Shown); Library > Copy Selected to… copies the marked files to a
  chosen folder/drive (e.g. all 5-star tracks), either Flat or Organized into
  Artist/Album folders. Collisions get a " (2)" suffix.
- Filename column auto-sizes to fit the longest name; the table scrolls
  horizontally on narrow windows.
- Copy Selected now shows a progress dialog with a progress bar and the current
  filename ("Copying 3 of 50: song.flac"), plus a Cancel button that stops before
  the next file. A summary reports how many copied / failed (and if cancelled).

Version 0.1.0 - June 8, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW Cross platform media player
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- SQLite media catalog across multiple watched folders (pure-Go modernc driver)
- Spreadsheet-style track table with embedded album-art thumbnails
- Play tracking: play count + 1-5 star rating; manual stars or auto-rating from play count
- Rating filters: exact stars, N-and-up, played, unplayed
- In-row clickable stars + right-click row menu
- Portable library: track paths stored relative to folder root; relocate a moved
  drive (D: -> E:) via Library > Relocate Folder; DB location configurable (-db / KBMP_DB)
- Sequence playback (MP3/FLAC/WAV/OGG) via gopxl/beep; double-click a row to play
- Selection indicator follows the now-playing track as it changes
- A play is credited after a configurable % of the track (View > Count play after:
  25/50/75/90/end), updating play count + auto-stars live; manual ratings are never
  changed; skipping never counts
- Live search box (title / artist / album / genre / filename)
- Click column headers to sort (tap again to reverse); Art column excluded
- Volume slider and seek bar with elapsed/total time
- System tray icon + menu (Show/Hide all windows, Play/Pause, Prev, Next, Stop, Quit)
- Hide all / show all windows together (main + Help/About/Update) via menu + tray
- Hotkeys: Alt+P play/pause; Alt+H "boss key" hides all windows AND pauses
  (no hotkey to show/resume by design - reveal via tray/menu, then press play)
- Remembers and restores the window size at next launch (size only; Fyne can't
  save window position/display)
- Optional Track # and Filename columns (View menu, off by default, remembered)
- Smaller About and Update windows; icons sized to 128px (Contain)
- Update checker shows the HardHat bear when the local build is newer than the
  latest release, otherwise the normal app icon
- Reliable quit on Windows/macOS/Linux via the window X, main menu, or system tray
- Linux .deb/.rpm install an application-menu launcher (.desktop) + themed icon
- Windows EXE icon embedded via go-winres and regenerated on every build
