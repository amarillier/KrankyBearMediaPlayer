KrankyBear MediaPlayer: - Windows, Linux and MacOS media player

✨ NEW FEATURES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Per-column filters (View → Show Column Filters): a row of filter boxes that
  narrow the list live — type a substring in Title / Artist / Album / Genre, and
  Year takes a pattern (202[456] matches 2024-2026, 20* the 2000s). They combine
  with each other, the search box, and the Show/rating filter. A ✕ clears them;
  hiding the row clears them too.
- New optional Genre column (View menu / Preferences).
- Smart playlists can now be edited: Playlists → Manage Smart Playlists… gives each
  one a pencil button that reopens its criteria (and lets you rename it), instead of
  having to delete and recreate.
- Tooltips: hover the toolbar and transport buttons for a short description of each.
- Batch tag editing (Library → Edit Tags of Selected…): mark a set of tracks,
  tick the fields to change (Artist, Album, Album Artist, Genre, Year, Comment),
  and they're written to every marked file at once — great for tagging a whole
  album. Only the ticked fields change; each track's title, track number and
  cover art are left untouched. A progress dialog shows each file and can be
  cancelled. MP3 and FLAC are written; OGG/WAV are skipped.
- The KrankyBear logo is now shown at the bottom-left of the window, always
  visible while you play.

🐛 FIXES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Play/Pause now restarts the current track after Stop. Previously, once you
  pressed Stop the Play button appeared to do nothing (you had to double-click a
  track, or use Previous/Next) because the player still treated a track as
  "current" even though its audio stream had been released.

Version 0.4.0 - June 10, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW FEATURES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Now-playing enrichment: new optional Length, Format, and Bitrate columns (View
  menu / Preferences; Length shown by default). Track length isn't in the tags, so
  the app computes it in the background after launch and after a scan and caches it
  in the catalog — Length/Bitrate populate within moments and persist. Bitrate is
  an average derived from file size and length. Jump to the currently-playing
  track by clicking its name in the bottom bar or the toolbar "Now Playing"
  button (handy after scrolling, searching, or sorting away; it locates the
  track without starting playback).
- Keyboard shortcuts: Alt+→ / Alt+← skip to the next / previous track, and
  Preferences is on Alt+R (Cmd/Ctrl-based shortcuts weren't firing on macOS).
  All shortcuts are wired on the window canvas now, so they trigger reliably.
- Pick up where you left off: the sort order (primary + secondary column and
  direction) is remembered across launches, and on relaunch the app selects and
  scrolls to the track you were last playing — without starting playback.
- Tag editor (right-click a track → Edit tags…): edit title, artist, album,
  album artist, year, track #, genre, comment, and the embedded cover image, and
  write them back into the file. Supported for MP3 (ID3v2) and FLAC (Vorbis
  comments + picture); OGG and WAV open read-only for now. Editing the track
  that's playing stops playback first so the file can be saved (needed on
  Windows). The catalog and thumbnail update immediately, without a re-scan, so
  play counts and ratings are untouched. (Renaming files from tags is still to
  come.)
- System volume control: a second slider ("Sys") at the bottom right drives your
  computer's master output level, with a mute toggle beside it. It stays in sync
  with the system volume, including changes you make with the volume keys or the
  OS mixer. The existing slider (now labelled "App") still adjusts only this
  player's own level. Both platforms drive the default output device in-process
  via the OS audio API directly (CoreAudio on macOS, CoreAudio/WASAPI COM on
  Windows) — no helper processes are spawned.

Version 0.3.0 - June 8, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW FEATURES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- New Playback menu with Shuffle and Repeat (Off / All / One), both remembered
  across launches. Shuffle keeps the current track playing then randomises the
  rest; Repeat All loops the queue, Repeat One loops the current track. Next /
  Previous always skip on, even under Repeat One. Transport (Play/Pause, Previous,
  Next, Stop) is now in this menu too.
- Play Queue window (Playback → Show Play Queue): shows the upcoming tracks in
  play order with the current one marked ▶. Add to Queue from a track's right-click
  menu, or Library → Add Selected / Add All Shown to Queue, appends without
  interrupting playback. In the window you can Play a chosen track, Remove one,
  move tracks Up/Down, or Clear All.
- Playlists menu. Static playlists: Save Playlist… writes the current view to a
  portable .m3u8 (paths relative to the file, so playlist + music travel together);
  Open Playlist… loads and plays one (catalogued files keep their stars/plays).
  Smart playlists: New Smart Playlist… saves filter criteria (rating + optional
  Genre/Artist/Album, matched partially & case-insensitively, + Search) under a
  name; picking it from the menu re-applies them live (status bar shows ♫ name).
  Manage Smart Playlists… deletes.
- Preferences window (View → Preferences…, Cmd/Ctrl+,): one place for theme,
  "count a play after" threshold, the optional columns, the database location
  (with a restart note), and playback volume — which is now remembered across
  launches. The quick toggles stay on the View menu too.
- Selection checkboxes are now instant: they toggle on mouse-down (previously the
  double-click detection delayed each tick by the system double-click time) and
  refresh only the tapped cell.

Version 0.2.0 - June 8, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW FEATURES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Multi-column sort: click a header to sort, Shift+click another for a secondary
  tie-breaker (e.g. Album then Track #). Large arrow = primary, small = secondary.
- Discreet update check: an automatic once-per-day check on launch (shows the
  dialog only if an update is available); the manual "Check for Updates" still
  works any time. Cache stored per-user as latestcheck-KrankyBearMediaPlayer.json.
- Add album art (right-click a track) from a local image file or a URL; stored in
  the library and shown in the table + now-playing. No online cover search.
- Right-click: Show in Finder/Explorer/File Manager, and Show full path (copyable)
- Select & copy: View > Selection checkboxes adds a tick column (or Library >
  Select All Shown); Library > Copy Selected to… copies the marked files to a
  chosen folder/drive (e.g. all 5-star tracks), either Flat or Organized into
  Artist/Album folders. Collisions get a " (2)" suffix.
- Filename column auto-sizes to fit the longest name; the table scrolls
  horizontally on narrow windows.
- Copy Selected now shows a progress dialog with a progress bar and the current
  filename ("Copying 3 of 50: song.flac"), plus a Cancel button that stops before
  the next file. A summary reports how many copied / failed (and if cancelled).

Version 0.1.0 - June 8, 2026
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✨ NEW Cross platform media player
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- SQLite media catalog across multiple watched folders (pure-Go modernc driver)
- Spreadsheet-style track table with embedded album-art thumbnails
- Play tracking: play count + 1-5 star rating; manual stars or auto-rating from play count
- Rating filters: exact stars, N-and-up, played, unplayed
- In-row clickable stars + right-click row menu
- Portable library: track paths stored relative to folder root; relocate a moved
  drive (D: -> E:) via Library > Relocate Folder; DB location configurable (-db / KBMP_DB)
- Sequence playback (MP3/FLAC/WAV/OGG) via gopxl/beep; double-click a row to play
- Selection indicator follows the now-playing track as it changes
- A play is credited after a configurable % of the track (View > Count play after:
  25/50/75/90/end), updating play count + auto-stars live; manual ratings are never
  changed; skipping never counts
- Live search box (title / artist / album / genre / filename)
- Click column headers to sort (tap again to reverse); Art column excluded
- Volume slider and seek bar with elapsed/total time
- System tray icon + menu (Show/Hide all windows, Play/Pause, Prev, Next, Stop, Quit)
- Hide all / show all windows together (main + Help/About/Update) via menu + tray
- Hotkeys: Alt+P play/pause; Alt+H "boss key" hides all windows AND pauses
  (no hotkey to show/resume by design - reveal via tray/menu, then press play)
- Remembers and restores the window size at next launch (size only; Fyne can't
  save window position/display)
- Optional Track # and Filename columns (View menu, off by default, remembered)
- Smaller About and Update windows; icons sized to 128px (Contain)
- Update checker shows the HardHat bear when the local build is newer than the
  latest release, otherwise the normal app icon
- Reliable quit on Windows/macOS/Linux via the window X, main menu, or system tray
- Linux .deb/.rpm install an application-menu launcher (.desktop) + themed icon
- Windows EXE icon embedded via go-winres and regenerated on every build
