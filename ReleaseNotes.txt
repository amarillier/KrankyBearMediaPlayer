- Missing track cleanup on scan: when you Scan or Rescan, the player now notices any
  catalogued tracks whose files have disappeared from disk — for example deleted or moved
  in Finder, Explorer or a shell, outside the app. It lists the missing tracks and offers
  to remove them from the library in one step (the files on disk are not touched — there's
  nothing left to remove). Nothing is deleted without your confirmation, so you can simply
  Keep them if the drive is just temporarily unavailable. If you moved a whole folder, use
  Manage Folders → Relocate instead, which repoints every track at once.
- Alt+S — Show all windows: brings the main window and every open secondary window
  (equalizer, help, and so on) to the front. Handy when the player is buried behind other
  apps. Because it fires on the main window, it works while the player is visible; after
  Alt+H (Hide all) use the system tray or View → Show All Windows to reveal them again.

- Delete files (right-click a track → Delete file…, or Library → Delete Selected Files…):
  permanently remove one or more files from disk and the library in one step — handy for
  clearing out corrupted tracks or downloads you've decided against. A confirmation dialog
  lists every file first, since this cannot be undone (there's no trash step). Right-clicking
  an unmarked track deletes just that one; right-clicking a marked (✓) track, or using the
  Library menu, deletes the whole marked set. If the currently-playing track is among them,
  playback stops first so the file can be removed. To take a track out of the library but
  keep the file on disk, use Manage Folders instead.

- Equalizer (Playback → Equalizer…): a 10-band graphic EQ (31 Hz – 16 kHz, ±12 dB)
  that shapes playback tone in real time. Built-in presets — Flat, Bass Boost,
  Treble Boost, Vocal, Rock, Classical, Pop, Jazz, Dance, Loudness — and you can
  save your own slider settings as named custom presets (and delete them later).
  Enable/disable, band positions and the last preset are all remembered. Disabling
  it is completely transparent (no effect on the audio). A new Preferences option,
  "Open equalizer on startup", reopens the EQ window automatically at launch.
- Stereo balance ("Bal" slider, bottom right beside the volume controls): shift the
  left/right balance for speakers that aren't placed symmetrically, or to favour one
  ear. It has a soft center detent and a "C" button that snaps back to dead-center;
  center is a true bypass (no effect on the audio). The position is remembered across
  launches and applies live to whatever is playing.

▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Scan ReplayGain (Library → Scan ReplayGain of Selected…, or right-click): the
  app can now MEASURE loudness and WRITE the ReplayGain tags itself — no external
  tool needed. It analyses each marked MP3/FLAC (ITU-R BS.1770 / ReplayGain 2.0,
  -18 LUFS reference) and writes replaygain_track_gain/_peak plus album_gain/_peak
  (album values pool every scanned track of the same album). A progress dialog
  shows each file and can be cancelled; OGG/WAV are skipped. Pairs with the
  existing Playback → ReplayGain toggle, which reads these tags.
- Playback → "ReplayGain: prefer album gain": when album-gain tags are present,
  normalize by album loudness (keeps an album's quiet/loud track balance) instead
  of per-track. Falls back to track gain when album gain isn't tagged.
- Library Report (Library → Library Report…): summarise your library grouped by
  Artist, Album, or Genre; hierarchically (Artist → Album, Album → Artist, Genre →
  Artist); or as a flat track listing. "List tracks" expands each grouping to show
  the tracks within it. Sort by Name or Year (ascending/descending), report on the
  whole library or just the current filtered view, and export any report to CSV.

🐛 FIXES
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- MP3 tag writing no longer corrupts files whose tags use UTF-16 text (common in
  store-bought downloads, e.g. Amazon). The underlying ID3 library wrote those
  frames with a bad length; affected files became unreadable. We now save such
  text as UTF-8. This covers Edit Tags, batch tagging, rename, and the new
  ReplayGain scan. Re-saving an already-damaged file (e.g. Scan ReplayGain again)
  repairs it.

- Rename files from tags (right-click → Rename file…): build a filename from a
  track's tags using a pattern of tokens — %track% %title% %artist% %album%
  %albumartist% %year% %genre% — e.g. "%track% %title% - %artist%". A live preview
  shows the new name before you apply; the extension is always kept, %track% is
  zero-padded to two digits, and the catalog updates in place (no re-scan).
- Rename a whole selection (Library → Rename Selected from pattern…): the same
  pattern applied to every marked track, with an old → new preview list before you
  commit. Name clashes get a " (2)" suffix; nothing is overwritten; cancellable.
- Tags from filename (Edit tags… → Tags from filename): the inverse of rename —
  parse a file's name into tag fields using the same token pattern, with an
  optional "leading track number". It fills the editor fields for you to review;
  it never writes on its own.
- Batch tag editor, expanded (Library → Edit Tags of Selected…): three kinds of
  change you can combine in one pass — (1) From filename: set title/artist/track #/
  etc. per track by parsing each name with a pattern; (2) Set fields: give Artist/
  Album/Album Artist/Genre/Year/Comment one value across the whole selection
  (these override the pattern); (3) Cover art: set one image as the cover for all,
  or remove the cover from all.
- Right-click Edit tags… / Rename file… now follow the selection: right-click a
  marked (✓) track and they act on the whole marked set — the menu label says
  which (e.g. "Edit tags of 5 marked…"). Right-click an unmarked track and they
  act on just that one, as before.

- Watched-folders manager (Library → Manage Folders…): view every watched folder
  with its track count; add, relocate (repoint at a moved/re-lettered drive),
  rescan a single folder, or remove one. Removing takes a folder's tracks out of
  the library but never deletes files on disk.
- ReplayGain (Playback → ReplayGain): optional per-track volume normalization for
  files tagged with ReplayGain, so albums/playlists play at a consistent loudness.
  Peak-limited to avoid clipping. Off by default; reads MP3/FLAC/OGG tags.
- Track transitions (Playback → Track transition): Gapless plays tracks back-to-
  back with no silence; Crossfade fades the outgoing track out as the next fades
  in. Default stays "Gap". (Both new modes are experimental.)
- Ratings are now manual-only. Stars are what you set; a track's play count is
  tracked and shown in its own column but no longer turned into auto-stars (which
  was confusing — "Clear" now truly goes to no stars). The Show filter's
  "Unplayed (no stars)" became "Unrated"; "Played (1+ stars)" became "1 star & up".
- Per-column filters (View → Show Column Filters): a row of filter boxes that
  narrow the list live — type a substring in Title / Artist / Album / Genre, and
  Year / Plays take a pattern (Year 202[456] matches 2024-2026; Plays 5 = exactly
  five plays, 0 = unplayed). They combine with each other, the search box, and the
  Show/rating filter. A ✕ clears them; hiding the row clears them too.
- New optional Genre column (View menu / Preferences).
- Smart playlists can now be edited: Playlists → Manage Smart Playlists… gives each
  one a pencil button that reopens its criteria (and lets you rename it), instead of
  having to delete and recreate.
- Tooltips: hover the toolbar and transport buttons for a short description of each.
- Batch tag editing (Library → Edit Tags of Selected…): mark a set of tracks,
  tick the fields to change (Artist, Album, Album Artist, Genre, Year, Comment),
  and they're written to every marked file at once — great for tagging a whole
  album. Only the ticked fields change; each track's title, track number and
  cover art are left untouched. A progress dialog shows each file and can be
  cancelled. MP3 and FLAC are written; OGG/WAV are skipped.
- The KrankyBear logo is now shown at the bottom-left of the window, always
  visible while you play.

▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Now-playing enrichment: new optional Length, Format, and Bitrate columns (View
  menu / Preferences; Length shown by default). Track length isn't in the tags, so
  the app computes it in the background after launch and after a scan and caches it
  in the catalog — Length/Bitrate populate within moments and persist. Bitrate is
  an average derived from file size and length. Jump to the currently-playing
  track by clicking its name in the bottom bar or the toolbar "Now Playing"
  button (handy after scrolling, searching, or sorting away; it locates the
  track without starting playback).
- Keyboard shortcuts: Alt+→ / Alt+← skip to the next / previous track, and
  Preferences is on Alt+R (Cmd/Ctrl-based shortcuts weren't firing on macOS).
  All shortcuts are wired on the window canvas now, so they trigger reliably.
- Pick up where you left off: the sort order (primary + secondary column and
  direction) is remembered across launches, and on relaunch the app selects and
  scrolls to the track you were last playing — without starting playback.
- Tag editor (right-click a track → Edit tags…): edit title, artist, album,
  album artist, year, track #, genre, comment, and the embedded cover image, and
  write them back into the file. Supported for MP3 (ID3v2) and FLAC (Vorbis
  comments + picture); OGG and WAV open read-only for now. Editing the track
  that's playing stops playback first so the file can be saved (needed on
  Windows). The catalog and thumbnail update immediately, without a re-scan, so
  play counts and ratings are untouched. (Renaming files from tags is still to
  come.)
- System volume control: a second slider ("Sys") at the bottom right drives your
  computer's master output level, with a mute toggle beside it. It stays in sync
  with the system volume, including changes you make with the volume keys or the
  OS mixer. The existing slider (now labelled "App") still adjusts only this
  player's own level. Both platforms drive the default output device in-process
  via the OS audio API directly (CoreAudio on macOS, CoreAudio/WASAPI COM on
  Windows) — no helper processes are spawned.
